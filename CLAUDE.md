# Istruzioni di progetto

## Skill obbligatorie

All'inizio di ogni task che riguarda la scrittura, il refactoring o la review di
codice, invoca **sempre** la skill `andrej-karpathy-skills:karpathy-guidelines`
prima di procedere, e segui le sue linee guida (modifiche chirurgiche, niente
overcomplication, esplicita le assunzioni, definisci criteri di successo
verificabili).
